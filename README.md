# Swirl

A college dating app with a live, like-based campus leaderboard. Launching at CU Boulder first.

## What's here

- `prototype/Swirl.jsx` — the clickable web prototype (React + Tailwind + lucide-react, all mock data). This is the design reference for the real app.

## Coming next

- `app/` — the real iOS/Android app (Expo / React Native)
- `supabase/` — database schema, auth, and server functions
